# ashdown releases

[ashdown](https://ashdown-site.vercel.app) — 읽기 위해 만든 macOS 마크다운 에디터의 배포 파일 저장소입니다.

**최신 버전 다운로드**: https://github.com/asherKiiim/ashdown-release/releases/latest/download/ashdown-universal.dmg

- Apple Silicon과 Intel Mac 모두 지원하는 universal 빌드입니다. macOS 13 이상.
- 코드 서명이 되어 있지 않아 첫 실행 시 macOS가 막습니다. 시스템 설정 → 개인정보 보호 및 보안 → 아래로 스크롤 → **그래도 열기**를 한 번 누르면 이후로는 묻지 않습니다.
- 버그와 요청은 [issues](https://github.com/asherKiiim/ashdown-release/issues)에 남겨주세요.
